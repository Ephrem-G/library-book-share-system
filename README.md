# library-book-share-system
This is my computer sci end of year project about a web app that allows sharing of books and communication of users outside the traditional library enviroment and within their specified geo location

## Technologies

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Google Maps API

## Installation

1. Import database/library_book_share.sql
2. Configure .env
3. Start Apache and MySQL
4. Open the application

- User Registration
- Email Verification
- Book Sharing
- Book Requests
- Messaging
- Google Maps
- Admin Dashboard
- Reports
